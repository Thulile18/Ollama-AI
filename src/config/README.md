# config

**What is in here:** every setting the app uses, in one place.

| File | What it holds |
| --- | --- |
| `settings.ts` | The Ollama address, the model name, the app name, the user name, the save key, and the system message that tells the AI who it is |

To change the AI model, the names or the system message, edit `settings.ts`.
Nothing else in the code needs to change.
